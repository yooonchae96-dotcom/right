# 발표 대본 제출·채점 웹앱 — 처음부터 따라하기

이 문서만 순서대로 따라 하시면 됩니다. 컴퓨터 용어를 몰라도 괜찮아요.

---

## 이게 뭔가요?

학생이 인터넷 주소로 들어와서 발표 대본을 쓰고 제출하면, AI가 피드백을 주는 사이트입니다.
선생님은 같은 주소에서 교사 화면으로 들어가 점수를 확인하고 엑셀로 받을 수 있어요.

**선생님이 직접 바꿀 값은 딱 4개입니다.** 나머지는 다 만들어 놨어요.

---

## 미리 알아둘 것

세 가지 서비스를 씁니다. 전부 무료예요.

| 이름 | 하는 일 | 쉽게 말하면 |
|---|---|---|
| 파이어베이스 | 구글 로그인, 학생 글 저장 | **창고** |
| 제미나이 | 대본 읽고 피드백 쓰기 | **채점하는 AI** |
| 깃허브 + Vercel | 사이트를 인터넷에 띄우기 | **사이트를 올려 두는 곳** |

---

# 1단계 · 창고 만들기 (파이어베이스)

학생 글을 저장할 곳을 만듭니다. 10분쯤 걸려요.

1. [console.firebase.google.com](https://console.firebase.google.com) 에 들어가서 **구글 계정으로 로그인**하세요.
2. **프로젝트 만들기**를 누르세요.
3. 이름을 아무거나 적으세요. (예: `발표대본`)
4. 애널리틱스를 켤지 물어보면 **끄고** 넘어가세요.
5. 만들어지면 왼쪽 메뉴에서 **빌드 → Authentication**을 누르고 **시작하기**를 누르세요.
6. 목록에서 **Google**을 고르고, **사용 설정**을 켠 다음 **저장**하세요.
7. 다시 왼쪽 메뉴에서 **빌드 → Firestore Database**를 누르고 **데이터베이스 만들기**를 누르세요.
8. 위치는 **asia-northeast3 (서울)** 을 고르세요.
9. **프로덕션 모드로 시작**을 고르고 만드세요.

> 돈 내라는 안내가 나와도 무시하세요. 무료 그대로 두시면 됩니다. 한 반 30명은 무료 범위 안입니다.

---

# 2단계 · 값 옮겨 적기

## 2-1. 창고 주소 받아오기

1. 화면 왼쪽 위 **⚙ 톱니바퀴 → 프로젝트 설정**을 누르세요.
2. 아래로 내리면 **내 앱**이 있습니다. **`</>`** 모양 아이콘을 누르세요.
3. 이름을 아무거나 적고 **앱 등록**을 누르세요.
4. 이런 글자 덩어리가 나옵니다.

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "발표대본.firebaseapp.com",
  ...
};
```

**`{` 부터 `}` 까지 전부 복사**해 두세요.

## 2-2. .env 파일에 적기

⚠ **개인정보와 API 키는 코드 파일에 적지 않습니다.** 전부 `.env` 파일에 넣습니다.
`.env` 는 깃허브에 올라가지 않으니 안전합니다.

1. 폴더 안의 **`.env.example`** 파일을 복사해서 이름을 **`.env`** 로 바꾸세요.
   (터미널이면 `copy .env.example .env`)
2. `.env` 를 열어 빈 칸을 채우세요.

```
GEMINI_API_KEY=AIza...              ← 4단계에서 받을 열쇠
OWNER_EMAIL=선생님@학교주소          ← 교사 화면에 들어갈 계정
ALLOWED_DOMAIN=학교주소              ← 학생 계정 @ 뒷부분. 비우면 모든 계정 허용

FIREBASE_API_KEY=AIza...            ← 2-1에서 복사한 덩어리에서
FIREBASE_AUTH_DOMAIN=프로젝트.firebaseapp.com
FIREBASE_PROJECT_ID=프로젝트
FIREBASE_STORAGE_BUCKET=프로젝트.appspot.com
FIREBASE_MESSAGING_SENDER_ID=000000000000
FIREBASE_APP_ID=1:000000000000:web:xxxx
```

학번이 6자리면 아래 한 줄을 더 적으세요. (5자리면 안 적어도 됩니다)

```
HAKBEON_PATTERN=\d{6}
```

저장하세요. (Ctrl+S)

> `public/config.js` 는 이 값들을 `.env` 에서 자동으로 받아 씁니다. 그 파일은 고칠 필요가 없습니다.

# 3단계 · 잠금장치 걸기

학생이 4번째 제출을 못 하게 막는 설정입니다. 이걸 안 하면 규칙이 작동하지 않아요.

1. 안티그래비티에서 **`firestore.rules`** 파일을 여세요.
2. 맨 위쪽에 이런 줄이 있습니다.

```
return 'PUT-YOUR-EMAIL-HERE@example.com';
```

따옴표 안을 **선생님 구글 계정**으로 바꾸고 저장하세요.

3. 이 파일 내용을 **전부 복사**하세요. (Ctrl+A → Ctrl+C)
4. 파이어베이스 화면으로 가서 **Firestore Database → 규칙** 탭을 누르세요.
5. 거기 있던 내용을 **전부 지우고** 복사한 것을 붙여넣으세요.
6. **게시** 버튼을 누르세요.

---

# 4단계 · 채점 AI 열쇠 받기

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에 들어가세요.
2. **API 키 만들기**를 누르세요.
3. `AIza…` 로 시작하는 긴 글자가 나옵니다. **복사해서 메모장에 붙여넣어 두세요.** 6단계에서 씁니다.

> 이 열쇠는 **파일에 적지 마세요.** 나중에 Vercel 화면에서 따로 넣습니다. 그래야 인터넷에 공개되지 않아요.

---

# 5단계 · 깃허브에 올리기

깃허브는 코드를 보관하는 곳입니다. Vercel이 여기서 코드를 가져다 사이트를 만듭니다.

**안티그래비티에서 하는 방법**

1. 왼쪽에 가지가 갈라진 모양 아이콘(소스 제어)을 누르세요.
2. **Publish to GitHub** 또는 **깃허브에 게시** 버튼을 누르세요.
3. 저장소 이름을 아무거나 정하세요. (예: `daebon-app`)
4. **Private(비공개)** 과 **Public(공개)** 중 아무거나 고르셔도 됩니다. 열쇠는 파일에 없으니까요.
5. 올라갈 때까지 기다리세요.

**버튼이 안 보이면** 아래 다섯 줄을 터미널에 한 줄씩 붙여넣으세요. (`사용자이름`과 `저장소이름`만 본인 것으로)

```bash
git init
git add .
git commit -m "첫 업로드"
git remote add origin https://github.com/사용자이름/저장소이름.git
git push -u origin main
```

# 6단계 · 사이트 띄우기 (Vercel)

1. [vercel.com/new](https://vercel.com/new) 에서 **깃허브 계정으로 로그인**하세요.
2. 만든 저장소 옆의 **Import** 를 누르세요.
3. **Environment Variables** 칸을 펼치세요.
4. **`.env` 파일에 적은 값을 전부 똑같이 넣으세요.** (Name / Value 한 쌍씩)

   | Name | Value |
   |---|---|
   | `GEMINI_API_KEY` | 4단계에서 받은 `AIza…` |
   | `OWNER_EMAIL` | 선생님 구글 계정 |
   | `ALLOWED_DOMAIN` | 학교 계정 @ 뒷부분 |
   | `FIREBASE_API_KEY` | 파이어베이스 값 |
   | `FIREBASE_AUTH_DOMAIN` | 〃 |
   | `FIREBASE_PROJECT_ID` | 〃 |
   | `FIREBASE_STORAGE_BUCKET` | 〃 |
   | `FIREBASE_MESSAGING_SENDER_ID` | 〃 |
   | `FIREBASE_APP_ID` | 〃 |

5. 맨 아래 **Deploy** 를 누르세요.
6. 2~3분 뒤 주소가 나옵니다. **이 주소를 메모해 두세요.**

> 나중에 값을 고치려면 Vercel 프로젝트 → **Settings → Environment Variables** 에서
> 고치고 **Redeploy** 를 눌러야 반영됩니다.

# 7단계 · 마지막 두 가지

이 두 가지를 안 하면 사이트가 열려도 작동하지 않습니다. 꼭 하세요.

## ① 파이어베이스에 주소 알려 주기

안 하면 **로그인 창이 안 뜹니다.**

1. 파이어베이스 → **Authentication → 설정** 탭 → **승인된 도메인**
2. **도메인 추가**를 누르고 `daebon-app.vercel.app` 처럼 **주소만** 적으세요. (`https://` 는 빼고)

## ② 열쇠에 자물쇠 걸기

안 하면 다른 사람이 열쇠를 가져다 쓸 수 있습니다.

1. [console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials) 에 들어가세요.
2. 4단계에서 만든 키를 누르세요.
3. **애플리케이션 제한사항**에서 **HTTP 리퍼러**를 고르세요.
4. **항목 추가**를 누르고 `https://daebon-app.vercel.app/*` 처럼 적으세요. (뒤에 `/*` 꼭 붙이세요)
5. **API 제한사항**에서 **키 제한**을 고르고 `Generative Language API` 만 체크하세요.
6. **저장**하세요.

# 다 됐습니다

## 첫 실행

1. 만들어진 주소에 **선생님 계정으로 먼저** 들어가세요. 이때 설정이 자동으로 만들어집니다.
2. 위쪽 **교사** 탭을 누르세요.
3. **명렬표** 버튼을 눌러 반 학생 학번을 한 줄에 하나씩 붙여넣으세요.

## 수업할 때

1. **제출 열림** 스위치를 켜세요.
2. 학생들에게 주소를 알려 주세요. 학교 구글 계정으로 로그인하면 바로 씁니다.
3. 수업이 끝나면 스위치를 끄세요. 제출만 막히고 학생들은 계속 글을 쓰고 저장할 수 있어요.
4. **전체 채점**을 누르면 제출한 학생을 모두 채점합니다.
5. **엑셀 다운로드**를 누르면 점수와 과세특이 든 파일이 받아집니다.
6. 다음 차시에 또 쓰게 하려면 **횟수 초기화**를 누르세요.

# 막혔을 때

**로그인 창이 안 떠요**
7단계 ①을 안 하신 겁니다. 파이어베이스 승인된 도메인에 주소를 넣으세요.

**로그인은 되는데 "채점 실패"가 떠요**
열쇠 문제입니다. Vercel에서 `GEMINI_API_KEY`를 제대로 넣었는지, 7단계 ②에서 주소 뒤에 `/*` 를 붙였는지 확인하세요.

**교사 탭이 안 보여요**
`.env` 의 `OWNER_EMAIL`이 지금 로그인한 계정과 똑같은지 보세요. 띄어쓰기나 오타가 있으면 안 됩니다.

**학생이 로그인이 안 된대요**
`.env` 의 `ALLOWED_DOMAIN`이 학생 계정 주소의 `@` 뒷부분과 똑같은지 보세요.

**학번이 안 뜨고 빈칸이에요**
`HAKBEON_PATTERN`의 자릿수를 확인하세요. 학번이 6자리면 `\\d{6}` 이어야 합니다.

**글을 고쳤는데 사이트가 그대로예요**
고친 뒤 깃허브에 다시 올려야 합니다. 안티그래비티 소스 제어에서 커밋하고 **Sync** 또는 **Push**를 누르세요. Vercel이 알아서 다시 만듭니다. 2분쯤 걸립니다.

| 고치고 싶은 것 | 열 파일 |

| 채점 기준, 피드백 말투 | `public/prompts.js` |
